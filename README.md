## Prerequisites & Recommended Setup

To get the full Windows 7 / Vista Basic look alongside this mod, you will need a patched theme engine and a compatible visual style:

1. **Theme Patcher:** Install [SecureUxTheme](https://github.com/namazso/SecureUxTheme) or [UltraUxThemePatcher](https://mydigitallife.net) to enable custom third-party visual styles.
2. **Custom Visual Style:** Download and apply the [Aero10 Vista/Seven Theme by vaporvance](https://www.deviantart.com/vaporvance/art/Aero10-Vista-Seven-909711949).
3. **Windhawk Mod:** Apply this `Restore Basic Caption Buttons` mod following the installation steps below.
